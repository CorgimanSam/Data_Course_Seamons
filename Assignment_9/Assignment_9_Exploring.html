Logistic Regression of the Data

After looking at the graphs of the Admission data, I used a quadratic fit for the data, and the Percent similarity to the data is very strong.

# ==========================================
# LOGISTIC REGRESSION MODEL
# ==========================================

# Convert rank into a categorical variable
Grad_Admins$rank <- as.factor(Grad_Admins$rank)

# Fit logistic regression
mod1 <- glm(
  admit ~ I(gre / 100) + I(gpa * 10) + rank,
  data = Grad_Admins,
  family = binomial
)

# Examine model results
